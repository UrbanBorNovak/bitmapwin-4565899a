# Changelog

## 0.9.0-beta.2

- Guardians are mountable by their owners in the Oasis, with riding controls, roar, and dismount.
- Added Oasis Guardian encounters: Sovereign Stride speed boon and friendly non-lethal sparring.
- Marketplace buys now take a 90-second server-side checkout reservation against sniping, with a private mempool relay fallback for broadcasts.
- Awakened Guardians are tracked separately from inscribed, tradable collection children; only on-chain children can be listed.
- Rebuilt the Bestiary around a centered 3D stage with dossier index, filters, and combat specs.
- Added the closed-loop Bitcoin → Ordinals → BITMAP → DMT circuit infographic wired to live block data.
- Featured BITMAPs now show live Guardian mint status, and the homepage features the latest minted Guardian rendered on its real parcels.
- Reinscription images now render directly on the terrain surface; the ground itself is fully solid.
- Passport recolored to the shared site palette with a simpler first-steps guide.
