# Illustrated Oasis minimap background

## Build
- Add the uploaded artwork as a project-hosted image.
- Render it beneath the live minimap grid, terrain, owned BITMAPs, players, and heading marker.
- Crop and scale the artwork with the minimap zoom so nearby exploration and the full-world view stay aligned.
- Keep labels subdued enough that live markers and position readouts remain clear.

## Verify
- Check the compact minimap and full map at desktop size.
- Confirm the page loads without errors and existing map controls still work.
