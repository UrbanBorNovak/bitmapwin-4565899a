# Epic Advanced Passport

## Goal
Turn Passport into a living sovereign identity artifact while preserving real wallet, BITMAP, stamp, unlock, build, visit, blueprint, and provenance data.

## Build
- Recompose the signed-in page as an Evidence Grid led by a dominant Cyber Obsidian passport artifact.
- Add live identity status, evidence totals, progression, ownership, club memberships, capabilities, stamps, and recent history using existing records only.
- Upgrade the signed-out state into the same premium passport artifact with a focused sign-in action.
- Restyle estate, stamp, unlock, and timeline panels to match the new forensic identity system.
- Add restrained scan, reveal, and seal motion with reduced-motion support.
- Preserve the global shell, light mode, all existing links/actions, and mobile usability.

## Visual System
- Palette: Emerald Prestige (`#064E3B`, `#0D7A5F`, `#C9A84C`, `#F5F0E0`) expressed as Passport-only semantic tokens.
- Type: JetBrains Mono headings and Work Sans body.
- Geometry: square evidence modules around one distinctive physical passport artifact; no rounded generic cards.

## Validation
- Check signed-out Passport visually on desktop and mobile.
- Verify no horizontal overflow, broken interactions, page errors, or build errors.
