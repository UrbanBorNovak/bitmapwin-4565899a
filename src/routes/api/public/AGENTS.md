- Marketplace trading API (src/routes/api/public/market.$.ts): public reads; every write is proven by a seller PSBT, BIP-322 signature, or a buyer-signed PSBT, and reuses the same server helpers as the site. Why: bots and players trade under identical, key-free server rules.
- Trading API writes are rate-limited in the database (market_api_hit) and API signatures are timestamped (market-api-guard.ts) and single-use (market_api_claim_signature); holds are capped per buyer and holds cannot be released through the API. Why: limits must hold across workers and a captured signature must never act twice.
